## FeedLab 0.4.20 BETA TEST per Windows / for Windows

**Installazione / Installation:** `FeedLab-Setup-0.4.20.exe` (senza diritti di amministratore / no admin rights) oppure / or `FeedLab-0.4.20-portable.zip` → `FeedLab.bat`. Controllo del file scaricato / check the download: `SHA256SUMS.txt`.

### 🇮🇹 Novità
- **L'illuminazione cambia il feed:** il taper al bordo (o l'obiettivo) scelto nella procedura guidata ora modifica davvero le quote del feed, in tutte le schede, e si aggiorna subito; in Progetto feed è indicato l'f/D di progetto.
- **Fori nella base del feed** spostati nella scheda **Progetto feed**: riproducono la flangia della guida (WR-90, WR-75, WR-42, flange rotonde MIL) per fissare feed + piastrina a un tronchetto di guida esterno; la piastrina ha lo stesso pattern.
- **Applica modifiche:** anche spessore della parete e della base si applicano solo con il pulsante, come tutte le altre quote.
- **Testi uniformi:** interfaccia e disegni tutti in inglese o tutti in italiano, eliminate le frasi miste.

### 🇬🇧 What's new
- **The illumination changes the feed:** the edge taper (or the goal) chosen in the wizard now really changes the feed dimensions, in every tab, updated at once; Feed design shows the design f/D.
- **Holes in the feed base** moved to the **Feed design** tab: they reproduce the waveguide flange (WR-90, WR-75, WR-42, round MIL flanges) to fix feed + plate to an external waveguide section; the plate gets the same pattern.
- **Apply changes:** wall and base thickness are now applied only with the button, like every other dimension.
- **Consistent texts:** interface and drawings entirely in English or entirely in Italian, mixed sentences removed.

Requisiti / Requirements: Windows 10/11 64-bit.
