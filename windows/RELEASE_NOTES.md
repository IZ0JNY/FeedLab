## FeedLab 0.4.4 per Windows / for Windows

**Installazione / Installation:** `FeedLab-Setup-0.4.4.exe` (senza diritti di amministratore / no admin rights) oppure / or `FeedLab-0.4.4-portable.zip` → `FeedLab.bat`.

### 🇮🇹 Novità
- **Manuale d'uso in PDF**, in italiano e in inglese: pulsante **📖 Manuale** nella barra laterale (apre la lingua scelta), file anche in `docs/manual/`.
- Il repository si chiama ora **IZ0JNY/FeedLab**: link, pagina delle segnalazioni e installer aggiornati (i vecchi link continuano a funzionare).
- Comprende tutte le novità della 0.4.3: tolleranze di lavorazione e ottimizzazione robusta, space mapping con openEMS, fori di fissaggio piastra/feed (metrico o pollici, spine da 47 GHz), pulsante 🐞 Segnala un problema, verifiche Balanis, W5LUA e Pawlan WA6KBL, nuove parabole Kathrein e Fuba.

### 🇬🇧 What's new
- **PDF user manual**, in Italian and English: **📖 Manual** button in the sidebar (opens the chosen language), files also in `docs/manual/`.
- The repository is now **IZ0JNY/FeedLab**: links, issue page and installer updated (old links keep working).
- Includes everything from 0.4.3: fabrication tolerances and robust optimisation, openEMS space mapping, plate/feed fixing holes (metric or inch, pins from 47 GHz), 🐞 Report a problem button, Balanis, W5LUA and Pawlan WA6KBL checks, new Kathrein and Fuba dishes.

Requisiti / Requirements: Windows 10/11 64-bit.
