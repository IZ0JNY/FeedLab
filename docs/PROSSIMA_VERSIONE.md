## 1. Manuale in ogni lingua
- **Lingue:** le stesse dell'interfaccia e dell'installer (italiano, English, Deutsch, Français, Español).
- **File:** un PDF per lingua: `FeedLab_Manuale_IT.pdf`, `FeedLab_User_Manual_EN.pdf`, `FeedLab_Handbuch_DE.pdf`, `FeedLab_Manuel_FR.pdf`, `FeedLab_Manual_ES.pdf`.
- **Screenshot:** acquisiti automaticamente con l'interfaccia nella lingua del manuale (stesso progetto di esempio in tutte), con uno script ripetibile per ogni nuova versione.
- **Programma:** il pulsante 📖 Manuale apre il PDF della lingua scelta.
- **Installer:** include tutti i manuali; il collegamento nel menu Start apre quello della lingua scelta durante l'installazione.
